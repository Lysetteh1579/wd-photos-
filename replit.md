# Lysette Hernandez Photo Gallery

A responsive React + TypeScript photography showcase built with Vite and Tailwind CSS.

## Features
- **Header**: Features "Lysette Hernandez" and "DOB 11-17-2011" styled in cursive lettering.
- **Curated 3×3 Grid**: 9 themed photos with captions:
  - **Row 1 (Sunsets)**: Sunset Silhouette • Warm Beach Sunset • Rose Twilight Sunset
  - **Row 2 (Roses)**: Orange Roses • White Roses • Pink Roses
  - **Row 3 (Floral Blooms)**: Golden Rose Bloom • White Blossom Bouquet • Blush Rose Bloom
- **Interactive Lightbox**: Click any photo card to open a full-resolution preview modal with category tag and description.

## Running on Replit
- The **Start application** workflow runs `npm run dev`.
- The development server listens on `0.0.0.0:3000` mapped to Replit Webview Preview.
- Run `npm run build` for a production build.
- Run `npm run lint` to type-check the codebase.
