# Running on Replit

This project is Lysette Hernandez's personal portfolio, built with React, TypeScript, and Vite.

- The **Start application** workflow runs `npm run dev`.
- The development server listens on `0.0.0.0:5000` for Replit Preview.
- Run `npm run build` for a production build.
- Run `npm run lint` to type-check the project.
